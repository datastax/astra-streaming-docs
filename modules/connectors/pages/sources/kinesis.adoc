[#configs]
=== Kinesis source connector properties (`configs`)

Set these properties in the `configs` section of the connector configuration.

Properties provided in the https://pulsar.apache.org/docs/io-kinesis-source[OSS {pulsar} Kinesis source connector] are supported with the following exceptions:

* Properties that aren't relevant to {product}
* Properties that aren't present in {pulsar} {pulsar-version}
* Properties that are inherently unsupported by your environment
* Properties that are inherently unsupported by your xref:operations:astream-pricing.adoc[cluster deployment type]

For example, shared clusters cannot use `awsCredentialPluginName:org.apache.pulsar.io.aws.STSAssumeRoleProviderPlugin`.
